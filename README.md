# Paste Been

A minimal page for storing plain-text templates and copying them with one click.

- **+** adds a box
- **Edit / Done** unlocks or locks a box
- **Copy** puts the box's text on the clipboard as plain text
- **Export** downloads all templates as a file; **Import** adds templates from that file below your existing ones (nothing is replaced)

Templates are saved in your browser's local storage, so they stay on the device and browser you used to make them. Export now and then to keep a backup.
